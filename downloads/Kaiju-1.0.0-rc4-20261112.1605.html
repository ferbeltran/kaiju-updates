Kaiju 1.0.0 RC4

  • Dual View: the other Set List selects too: click, ⌘-click or ⇧-click its slots, ⌘A, ⌘C, or drag several at once into the Set List you're editing.
  • Delete (⌫) initializes the selected Set List slots.
  • Drag several Set List slots onto one of their own to move the block a few places: the slot you grabbed lands where you let go.
  • The selected Set List slot is yellow, as on the KRONOS.
  • Safer imports into a full PCG: empty slots that a Set List slot, a muted track or a Drum Track points at are filled last, and Use Unused Slots never offers a Program the import still plays.
  • Import no longer brings an empty Drum Track Program (it showed as "Init Program" among the Programs to copy).
  • New theme: Darker (Settings › Appearance).
